# 自选助手

“自选助手”把当前网页、来源候选和 B站关注列表发送到本机运行的“自选”。扩展不会读取或保存密码、Cookie、访问令牌，也不会调用平台未公开接口。

## 安装

1. 在项目根目录运行 `npm run dev`，确认可以打开 `http://localhost:3000`。
2. 在 Chrome 或 Edge 打开扩展管理页并启用开发者模式。
3. 选择“加载已解压的扩展程序”，选择本仓库的 `browser-extension/` 目录。
4. 在“自选 → 设置 → 浏览器助手”生成并复制配对码。
5. 打开扩展弹窗的连接设置，填写本地应用地址和配对码。

扩展只允许连接 `http://localhost:3000` 或 `http://127.0.0.1:3000`。配对码分别保存在应用与扩展的本地存储中，不进入备份。

## 收藏与订阅

- “稍后看”会把当前页面发送到系统合集“稍后再看”。
- “收藏到合集”会在自选确认页面中要求选择一个本地合集。
- “订阅这个来源”优先提交页面声明的 RSS/Atom，否则提交当前规范页面给自选已有的来源识别流程。

## B站关注导入

1. 打开 B站关注页并点击“开始新一轮”。
2. 滚动列表或切换分页，每次点击“扫描本页”；结果会按 MID 合并。
3. 覆盖全部需要的页面后点击“完成并发送”。
4. 在自选中预览、排除重复项并确认。相对上次快照不再出现的账号只用于提示，不会自动删除订阅。

页面改版可能影响 DOM 识别；扫描结果始终需要用户确认。扩展只读取页面中已经显示的公开名称、MID 和主页 URL。

## 恢复

如果本地通信暂时不可用，可以在扩展底部选择“导出待处理 JSON”。文件只包含待处理的公开页面元数据，不包含配对码或平台凭据。
